Funciones

Todo lo que esperas de un reproductor, con tus reglas

Wired guarda la música en tu dispositivo, en carpetas y formatos estándar. Nada queda atrapado en la app.

Fuentes por plugins

Busca con la fuente que elijas. Cada plugin aparece como un chip en el buscador, sin tocar vistas ni ViewModels.

Streaming o descarga

Toca un resultado para escucharlo al instante, o descárgalo a tu biblioteca con una cola en segundo plano, progreso y reintentos.

Sobrevive a la desinstalación

La música vive en la carpeta compartida Music/Wired y las listas como M3U. Tras reinstalar, Recuperar música reconstruye la biblioteca.

Me gusta y listas

Crea, renombra y ordena listas de reproducción. Todo se refleja en archivos M3U estándar que puedes llevarte a otra app.

Importar desde Spotify

Carga el CSV de Exportify. Cada canción se empareja puntuando duración, título y artista, y descartando versiones en vivo, covers o karaoke. Es reanudable.

Letras sincronizadas

Letras de LRCLIB con la línea actual resaltada. Toca una línea para saltar a ese momento, ajusta ±0,5 s y consúltalas sin conexión.

Cola con gestos

Desliza una canción para agregarla (con Deshacer), mantén presionado para el menú y reordena “A continuación” arrastrando.

Inicio con listas y mixes

Rankings y recomendaciones cuando la fuente lo permite (IDiscoverableMusicSource). Se guardan en el dispositivo y se actualizan al deslizar.

Volumen parejo

Normalización de volumen: Wired mide cada canción descargada y la ajusta al reproducir, sin saltos entre temas antiguos y modernos.

Temporizador para dormir

15, 30, 45 o 60 minutos, o al terminar la canción, con desvanecido final.

Android Auto y segundo plano

Navega Biblioteca, Me gusta y Listas desde el coche. Reproducción con notificación multimedia y controles en pantalla de bloqueo.

Peticiones con límite

El trabajo en segundo plano va a un ritmo moderado por fuente y, si esta pide frenar, se pausa con backoff exponencial y reintenta solo.

Cómo funcionan los plugins

Una interfaz, una fuente nueva

Un plugin es una librería que referencia Wired.Core. Si además implementa capacidades opcionales, la app las aprovecha sola.

  1. Crea el proyecto. Una librería Wired.Plugins.MiFuente que referencie Wired.Core.
  2. Implementa IMusicSourcePlugin. Búsqueda y descarga; devuelve la ruta del archivo.
  3. Regístralo. Expón AddMiFuenteMusicSource() y añádelo a AddMusicSources().
  4. Listo. Aparece como chip en el buscador. Para streaming suma IStreamableMusicSource; para el Inicio, IDiscoverableMusicSource.
public sealed class MiFuentePlugin : IMusicSourcePlugin
{
    public PluginInfo Info { get; } =
        new("mifuente", "Mi Fuente", "Descripción", "#22D3EE");

    public Task<IReadOnlyList<RemoteTrack>> SearchAsync(
        string query, int maxResults, CancellationToken ct)
    { /* ... */ }

    public Task<string> DownloadAsync(RemoteTrack track,
        string destinationDirectory,
        IProgress<double>? progress, CancellationToken ct)
    { /* devuelve la ruta del archivo */ }
}

Arquitectura

Las dependencias apuntan hacia dentro

Arquitectura limpia con MVVM. Los ViewModels no conocen MAUI: navegación, diálogos y el hilo de UI se inyectan como interfaces, así que se prueban con un dotnet test normal.

CoreModelos, casos de uso, cola de reproducción y descargas, límites de peticiones, importación y letras.
InfrastructurePersistencia JSON, cliente de LRCLIB, carátulas y etiquetas de audio.
PresentationViewModels con CommunityToolkit.Mvvm, sin referencias a MAUI.
AppVistas XAML, servicios de plataforma y raíz de composición.

Las pruebas con xUnit cubren dominio, infraestructura y ViewModels.

Empezar

Compila y ejecuta

Requisitos: SDK de .NET 10 y el workload de MAUI (dotnet workload install maui).

Android

dotnet build src/Wired.App -t:Run -f net10.0-android

Windows

dotnet build src/Wired.App -t:Run -f net10.0-windows10.0.19041.0

Pruebas

dotnet test tests/Wired.Tests

También puedes abrir Wired.slnx en Visual Studio 2026 o Rider y ejecutar Wired.App.
