Features

Everything you expect from a player, on your terms

Wired keeps your music on your device, in standard folders and formats. Nothing gets locked inside the app.

Sources as plugins

Search with the source you choose. Each plugin shows up as a chip in the search screen, with no changes to views or ViewModels.

Stream or download

Tap a result to listen right away, or download it to your library through a background queue with progress and retries.

Survives uninstalling

Music lives in the shared Music/Wired folder and playlists are saved as M3U. After a reinstall, Recover music rebuilds your library.

Likes and playlists

Create, rename and reorder playlists. Everything is mirrored to standard M3U files you can take to any other app.

Import from Spotify

Load your Exportify CSV. Each track is matched by scoring duration, title and artist, and skipping live versions, covers and karaoke. Imports are resumable.

Synced lyrics

Lyrics from LRCLIB with the current line highlighted. Tap a line to jump to that moment, fine-tune by ±0.5 s and read them offline.

Gesture-driven queue

Swipe a song to queue it (with Undo), long-press for the menu and drag to reorder “Up next”.

Home with charts and mixes

Charts and recommendations when the source supports them (IDiscoverableMusicSource). Cached on the device and refreshed with a pull.

Even loudness

Loudness normalization: Wired measures each downloaded song and adjusts it on playback, so there are no jumps between older and newer tracks.

Sleep timer

15, 30, 45 or 60 minutes, or at the end of the song, with a final fade-out.

Android Auto and background play

Browse Library, Likes and Playlists from the car. Playback with a media notification and lock-screen controls.

Rate limiting

Background work runs at a gentle pace per source and, if a source asks to slow down, pauses with exponential backoff and retries on its own.

How plugins work

One interface, a new source

A plugin is a library that references Wired.Core. If it also implements the optional capabilities, the app picks them up automatically.

  1. Create the project. A Wired.Plugins.MySource library that references Wired.Core.
  2. Implement IMusicSourcePlugin. Search and download; return the file path.
  3. Register it. Expose AddMySourceMusicSource() and add it to AddMusicSources().
  4. Done. It appears as a chip in search. Add IStreamableMusicSource for streaming, or IDiscoverableMusicSource for Home.
public sealed class MySourcePlugin : IMusicSourcePlugin
{
    public PluginInfo Info { get; } =
        new("mysource", "My Source", "Description", "#22D3EE");

    public Task<IReadOnlyList<RemoteTrack>> SearchAsync(
        string query, int maxResults, CancellationToken ct)
    { /* ... */ }

    public Task<string> DownloadAsync(RemoteTrack track,
        string destinationDirectory,
        IProgress<double>? progress, CancellationToken ct)
    { /* returns the file path */ }
}

Architecture

Dependencies point inward

Clean architecture with MVVM. ViewModels know nothing about MAUI: navigation, dialogs and the UI thread are injected as interfaces, so they can be tested with a plain dotnet test.

CoreModels, use cases, playback and download queues, rate limiting, import and lyrics.
InfrastructureJSON persistence, the LRCLIB client, cover art and audio tags.
PresentationViewModels with CommunityToolkit.Mvvm, no references to MAUI.
AppXAML views, platform services and the composition root.

xUnit tests cover the domain, infrastructure and ViewModels.

Get started

Build and run

Requirements: the .NET 10 SDK and the MAUI workload (dotnet workload install maui).

Android

dotnet build src/Wired.App -t:Run -f net10.0-android

Windows

dotnet build src/Wired.App -t:Run -f net10.0-windows10.0.19041.0

Tests

dotnet test tests/Wired.Tests

You can also open Wired.slnx in Visual Studio 2026 or Rider and run Wired.App.
